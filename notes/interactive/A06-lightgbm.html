Many small trees, each fixing the last one's mistakes

Start with one number for everyone. Each round, every visit gets a push: up by q if it would run late, down by 1 − q if the doctor would sit idle. A small tree groups visits that need a similar push into boxes, and each box moves a small step. Stop when June stops improving.
