A starting point plus one push per column

Every prediction the model makes can be split exactly into a starting point (its average prediction, the same for every visit) plus one push per column: how many minutes that column moves this visit up or down. The pushes add up exactly to the prediction. They are called SHAP values; LightGBM computes them itself. Because we wrote the simulator, we can also check a push against the hidden rule.
